# My Rules for This App

Security:
- [ ] No passwords stored in plain text
- [ ] Every API call goes through backend (not frontend direct to third-party)
- [ ] User A cannot see User B's data

User Experience:
- [ ] Works offline (cached data)
- [ ] Opens in < 2 seconds on dad's iPhone
- [ ] No typing if possible (dropdowns + toggles)

Money:
- [ ] Goal: 5,000 ETB from dad
- [ ] Future: Can add subscription for his friends
